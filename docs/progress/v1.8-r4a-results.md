## API 与数据契约

`GET /api/projects/:projectId/business` 是同源组合读接口，包含模块列表、当前选定模块、历史 revision、当前运营版本及业务 bindings、整窗卡片、按实际 activation period 分段的趋势、页面构成、身份规则、观察与覆盖说明、渗透率来源和当前工作流定义。参数沿用严格 R3 schema：env/range/from/to/metrics，增加 UUID moduleId/versionId。项目 IANA 时区以服务端为准。显式 versionId 与当前 active 不符返回409 `BUSINESS_ACTIVE_VERSION_CHANGED`，不混拼旧版本。

`GET/PUT /api/projects/:projectId/metrics/versions/:versionId/business-bindings` 复用草稿、复制、权限、审计和 review 摘要。最多24个绑定、16条总选择、同单位4条，最多800分段和10000配置交集。viewer 可读、筛选、查看定义，服务端拒绝写入。

同一 MySQL repeatable-read 快照固定 active、定义、bindings、模块/页面版本和工作流。释放事务后固定一条 ClickHouse 查询，按事件ID去重、事件时间revision归属、整窗/桶/页面常数组复制聚合。查询数量不随页面、卡片或桶增长。不返回 user_id、账号原值、payload。存储失败503 `FACT_STORE_UNAVAILABLE`，保留请求ID。无需新增数据库 schema/迁移；既有迁移保留回归。

URL：path projectId 为权威，公共时间/env继承 R3；moduleId/businessTrends/businessVersion/businessValues 为本页选择。缺省版本代表“当前active”，显式版本可固定校验；定义入口携带 metricVersion/metricKey/analysisReturn，返回原上下文。没有第二套导航或全局项目选择器。趋势默认正式值，可在 URL 选择明确标记的观察值趋势；观察模式不升级正式数据可用性。

`availableFrom` 是**所请求项目/env窗口内首次观察事件**，不是目录覆盖或实际保留起点证明。物理 raw_events 保留90天；长范围不补值。排除计数基于项目窗口，可重叠，不可相加。页面观察仅来自纳入本模块的已识别 page_view；完整业务UV仍未升级。正式比率和分位数只接受规范输入；无原始task/质量事实时保持不可用，不平均页面比率或分位数。
