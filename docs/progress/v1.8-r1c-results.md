## 3. 固定手算

固定示例是明确合成输入；`score-examples.ts` 只服务预览，实际 project query/history 不使用它。测试保留独立分子/分母 fixture，不反向调整公式凑数字。

| 运营维度       | 叶子原始值 → 分数（顺序同 §18.3）   | 维度分 | 默认权重 |  贡献 |
| -------------- | ----------------------------------- | -----: | -------: | ----: |
| 使用覆盖       | 0.8 → 80；0.9 → 90；1 → 100         |   88.5 |      30% | 26.55 |
| 持续使用与深度 | 0.35 → 70；6 页 → 50；3.5 模块 → 50 |     58 |      25% |  14.5 |
| 任务达成       | 0.86 → 90；0.18 → 80                |     87 |      30% |  26.1 |
| 使用效率       | 180000 ms → 50；0.75 → 75           |     60 |      15% |     9 |

正常总分 **76.15**。移除页面数、模块数、任务耗时和页面时长 4 项后，覆盖恰 70%、可参与维度恰 3，维度分 88.5/70/87；按维度权重 0.3/0.25/0.3 除以 0.85 重新归一化，总分 **82.5294117647**，实际贡献合计与总分一致。再缺任务成功率则不能通过 gate，不能返回同一分数。
