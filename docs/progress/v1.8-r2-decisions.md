## 接口与复用约束

- `/projects` 不依赖当前项目；300 ms 防抖，URL 保存 search/page/pageSize/env/range/from/to。默认 prod、最近 7 天；12/24/48，越界页回到最后有效页。创建后的 locate 只作用于授权搜索候选集。
- 多时区列表共享明确 UTC 瞬时边界 `[from,to)`，每张卡返回自己的 IANA timezone 和本地边界；预设天数来自 canonical manifest。不会用旧下拉框的时区解释全部项目。custom 最长 13 个月，沿用公共范围校验。
- 授权/搜索先执行，完整候选集聚合后告警优先、真实最近接收时间降序、id 升序，最后分页。一次事务 4 个元数据 SELECT（无候选时 1 个），一次 ClickHouse 批量观察查询；不循环读取单项目服务。
- R1-C 单项目与批量共用 `evaluateQuery`、evaluator、版本/定义快照和激活区间。运营/质量分别选 active；不创建公式副本。未配置和真实事实不足均可交付为明确不可用。
- 最近数据时间使用所选 env 的 ClickHouse `raw_events.received_at`，保留范围内事件计数与保留期内最近观察的区别。MySQL 的项目级链路问题仍显示 scope=project；env 健康完整性未验证时绝不声称 healthy。
- 新项目、Origin、owner membership、两类独立模板草稿、审计及重试键在同一 MySQL 事务提交。模板版本固定，业务 confirmed=false，无 review/自动激活。creationId 为用户作用域幂等键，同键不同输入 409。
- migration 003 只增加幂等请求表；不重写 001/002，不清现有数据。专用升级 verifier 在独立数据库验证真实保留数据升级。
