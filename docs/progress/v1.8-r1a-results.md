## 5. 数据与安全结论

- pre-1.0 空库基线直接重建，不保留已否决字段或旧状态兼容层；
- 稳定 identity 行保留唯一 key，revision 行保存有效期语义；归档不破坏历史引用；
- revision 更新、归档和恢复使用事务，审计与对象变更原子提交；
- API 错误返回依赖详情但不返回 selector、路径模式、业务 ID 或敏感 payload；
- `operationKey` 复用已登记 feature 身份，不新增第二套可编辑 operation 身份。

## 6. 已知非目标与后续边界

- **未实现 R1-B**：没有新增指标字典、公式 AST、DAG、指标版本库或血缘；
- **未实现 R4-B**：没有 workflow SDK collector、workflow/operation 实例关联、事实查询、漏斗或阶段耗时；页面只展示目标接入示例和准确边界；
