## 实施选择

- 复用项目、成员、Origin API、版本化概览和质量读模型，正式入口 `/projects/:projectId/settings`。创建项目复用 R2。旧入口仅登记 R8 清理。
- SDK 当前部署包 0.8.0、contract v3。最小接入使用实际部署提供的固定版本 ESM，不声称私有 workspace 包已经发布 npm。推荐版本仅允许部署提供的包；其他版本可配置 supported/deprecated/blocked，不自动升级业务项目。
- 探针策略项目隔离；blocked 必须显式确认并审计。collector 每请求查询策略，不使用项目缓存判定 blocked。历史事件不变。占比是项目/env/[from,to) 所有真实事件按 eventId 去重的份额，未知版本纳入分母。
- 外部接口复用既有 `export_interfaces/export_credentials`，默认关闭。256 位独立随机凭证只在签发响应显示一次，DB 仅 SHA-256 与前缀。接口/env/绝对时间范围/单次范围绑定，最多 90 天有效期。轮换无旧凭证宽限期；重新启用也签发新凭证。凭证不放日志、审计或列表。
- 新请求每次读取数据库授权；无授权缓存。每接口共享一分钟固定窗口，跨凭证、独立服务实例共享 MySQL 行锁；已存在接口的错误凭证尝试也计数。未存在接口和格式不合法的请求仍应由部署入口施加基础流量保护；不声称无限抵御任意网络攻击。
- Prometheus 仅固定服务、环境、状态、分数类型标签，版本化分数不可用时省略数值并返回 availability=0。完整版本血缘通过 JSON 快照/趋势读取，不把版本 ID 作为时序标签。
- 查询保护预算：50,000 返回事件、1,000,000 扫描行、256 MiB、5 秒；超过预算明确失败，非零值。

## 待管理层/安全评审：异常访问

本阶段只完成默认关闭的配置、不可变版本、批准记录登记、启停、调查计算与审计。不预置真实批准或启用规则。

规则阈值、适用环境、可见角色、工作时间、样本线、历史基线和例外必须整体评审。Owner 仅登记真实外部审批：管理层批准者、安全批准者、批准时间、来源及明确声明；系统记录登记账户与时间。管理员身份不是管理层/安全批准的替代。测试项目以 TEST ONLY 命名，审批 fixture 明确不代表真实批准。

1. 非工作时间高频：只计算已识别用户的去重显式操作开始，不用浏览量替代操作量；使用项目 IANA 时区和工作日/整点工作时间。
2. 历史操作量：历史有操作日均值与窗口内操作量/经过的 24 小时天数比较，样本不足不判断；仅表示观察值，不声称完整流量或个人绩效。
3. 多设备：同用户已观测显式操作的设备去重数；与多 IP 分开。没有 IP 事实，因此多 IP 不可计算。
4. 无权限路由拦截：当前 contract 没有可信拦截事实，返回不可计算，普通 page_view 不作替代。

共享账号整体排除；出差/值班例外只要与窗口重叠就排除整个用户窗口，避免部分分子对完整基线。可见角色来自已批准版本，读取、导出、命中审计；不排序形成个人排名。
