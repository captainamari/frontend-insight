# M8.1-B / P1 实现与验收记录

日期：2026-08-13

## 已实现闭环

| Collector        | schema / SDK                                                | 项目开关与回滚                                         | Read model / UI                       | 隐私与空态                                                |
| ---------------- | ----------------------------------------------------------- | ------------------------------------------------------ | ------------------------------------- | --------------------------------------------------------- |
| API summary      | `captureApiRequest`；method/path/status/duration 与请求分母 | 独立 enable/sample/slow threshold；global fetch 默认关 | P50/P90、成功/错误/慢率及各自分子分母 | path 归一化；无 query/header/body；`not_collected`        |
| Resource summary | pageView 离开汇总总数/失败/总耗时                           | 独立 enable/sample                                     | 失败次数、分母、失败率、coverage      | 不保存资源 URL 明细                                       |
| First screen     | 每 PV 一次显式 `markPageReady`                              | 独立 enable/sample                                     | template P50/P90、sample、coverage    | 无 DOM 文本推断                                           |
| List render      | `startListRender` begin/end                                 | 独立 enable/sample                                     | route × row bucket P50/P90            | 只发三档行数桶，不发 list key/行内容                      |
| Long task        | observer + pageView 离开汇总                                | 独立 enable/sample                                     | count/duration/affected PV rate       | 无 attribution 或脚本 URL                                 |
| Blank candidate  | readiness adapter 的 collected/state                        | 独立 enable/sample                                     | 候选数、检测分母、候选率              | UI 始终称“白屏候选”；无 adapter 不采集                    |
| Breadcrumb       | 错误事件附最多 50 条 ring                                   | 独立 enable/sample/action allowlist                    | 错误事件随行存储                      | 禁止 DOM/selector/input/console/query/header/body/业务 ID |

项目配置采用 clone-on-write 与审计；SDK 推荐使用 `createTrackerWithRemoteConfig` 在启动前拉取有效版本。公有配置接口校验项目注册 Origin，不返回内部项目或版本 ID；网络或校验失败时 P1 失败关闭，基础 page/feature 事件继续。

## 自动化证据

- Contract：v3 P1 全事件族正例、breadcrumb 隐私反例、v1/v2 明确拒绝、字段/事件/批大小边界。
- SDK：默认全关、显式 API/资源/readiness/list、pageView 汇总、白屏候选、错误专属 breadcrumb、全局 fetch 默认不包装、远程开关、hidden/pagehide 生命周期和宿主恢复。
- API：viewer 只读/admin 发新版本、公开配置 Origin gate、默认全关、响应不泄露内部标识。
- Read model：缺失分母为 null、0/0 不等于 0%；P50 五样本/P90 二十样本 gate。
- UI：页面分析显示 coverage/采样率/分子分母/样本不足/未采集，设置页显示七个独立开关、参数、证据与边界。

运行 `node tools/m8-p1-payload-report.mjs` 的固定 fixture 结果：7 个事件（含基础 page_view 和一个带 breadcrumb 的错误），事件大小 P50 418 B、P95 735 B，未压缩批 3361 B；低于 8 KiB 单事件与 64 KiB 批上限。这是确定性 payload gate，不是生产吞吐结论。
