## 实施选择

- 已有 contract v3/performance/小写 metric，直接扩展 canonical 清单及 schema；不重复旧名迁移，不接受 alias。
- 基础 SDK 12 KiB gzip 门禁保持；质量扩展独立导入 `/quality`，基础 SDK 不静态加载扩展。额外下载成本单独报告，不能把额外扩展声称为免费。所有开关默认关闭，不包装全局 fetch。
- Web Vitals 使用固定 web-vitals 5.3.0 standard build，不使用含 DOM attribution 的构建。按文档导航采样，不将文档级 Vitals 归给后来 SPA 路由。浏览器不支持时保留缺失，不模拟 0。
- 业务首屏从页面进入到显式完成；列表每次显式开始/完成独立样本，行数为 <100、100–1000、>1000。分位数继承普通样本线性插值 P50/P75/P90/P99；不改变评分工作流的池化算法。
- API/资源分母只来自显式适配器实际执行的请求。HTTP 200 业务拒绝仍是技术成功；HTTP >=400、网络及超时为技术错误。主动取消保留分母但不是成功或技术错误。未接入的请求不声称覆盖；资源 Timing 条目不能充当所有资源请求总数。
- 查询以页面开始 cohort 为边界，最多向后24h读取终态，双 event/received asOf。页面没有闭合、请求没结算、已知采样/丢失/限流、迟到窗口未结束均不输出正式值。保留89天安全范围和现有扫描/查询预算。
- 白屏固定 `root-empty-3s-v1`：显式页面模板/本地根选择器，在可见页面进入3秒后根缺失或没有子元素判为白屏。根选择器、DOM内容均不上传；早离开/隐藏未判断保持未结算。此规则是可解释的启发式，不是任意业务成功检测器。
- breadcrumb 最多50条固定语义枚举，仅随错误；不收点击文本或参数。错误原文不上传，新质量采集保留标准异常类型与安全首帧路径，最多100指纹、每指纹5条，抑制必须披露。
- 新定义版本 `r5a-facts-2026-10-04.1` 仅显式刷新质量草稿；active/历史快照、默认权重及旧结果不原地修改。结构化 Top/上下文不冒充标量AST输入。

这些是本次范围内实施选择，并非另行虚构的 Jesse 业务批准。R4-B Q07、跳步和 R4-C C06 隔离继续保留。
