## 接口与读模型

`GET /api/projects/:projectId/overview`，先授权，再 strict schema。query 为 `env=prod|staging|dev`、`range=7d|30d|90d|180d|365d|custom`，可选成对 RFC3339 `from/to`，可选逗号分隔 `metrics`。显式区间保留瞬时值。项目时区从授权项目元数据获取，拒绝 query 中伪造 project/timezone、非法环境、未知字段；最长 13 日历月，最多 400 日历桶/800 版本分段、24 张绑定卡片、16 条所选指标且每单位最多 4 条。响应含项目、query 本地与瞬时边界/桶、identity、链路和数据状态、真实 lastDataAt、availableFrom、独立 operational/quality、metrics 卡片/趋势/版本边界、alerts 证据及 diagnostics。所有失败沿用稳定错误码及 request ID。

`GET/PUT /api/projects/:projectId/metrics/versions/:versionId/overview-bindings`：读取绑定；管理员在草稿中保存 `metricKeys`（最多 24 个），引用 active 时创建/复用现有草稿。沿用项目角色校验、not_collected 引用限制、激活 review 和审计。不新增表或迁移，不添加共享偏好平台。

元数据采用 repeatable-read 一致快照；卡片、趋势和 score result 共享同一 active definition 快照。SQL 数由实际 SELECT 调用计数。CH 为保留数据观察、单次窗口/桶聚合及两个固定告警汇总；不逐指标/桶访问存储。历史版本区段只回传真实版本身份和不可用原因，不使用当前定义重算历史。

## 真实性与后置依赖

真实可查询 PV 观察按 eventId 去重、已识别 userId、事件时间匹配有效页面 revision；曝光完整性未验证时只能作为标明范围的原始观察，正式数值仍不可用。UV/VV、工作流、组织目录、质量真分母不从 PV 推导。运营/质量继续使用已批准 evaluator，真实配置有效不代表事实可计算。

实际 raw_events TTL 为 received_at 后 90 天；项目 retentionDays 不是物理保留期证明。365 天和 13 月性能只证明本环境保留数据的查询延迟，不证明生产容量。工作流事实属于 R4-B，操作与组织目录属于 R4-C/R7，质量真分母和后续页面事实属于 R5-A/R6；Q07 独立未决扩展不属 R3。
