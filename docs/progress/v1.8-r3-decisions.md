## 公共日历默认值（实施默认，非补记用户批准）

现有 canonical 只确定预设天数和 day/week/month，R1-C expected weekdays 使用 ISO 1–7，旧 range 使用 UTC 滚动窗口，均未明确项目周起点和预设是否含今天。反例：纽约 DST 周固定 168 小时不能表示本地周；R2 滚动 7 天跨 DST 不能重解释为项目零点范围。

选择为周一或周日；预设可含今日、前 N 个完整日或本地滚动时刻。推荐并暂作实施默认：周一，含今日，从第 N 个日期零点到当前瞬时。局部询问未收到答案，依照任务允许对常规可逆选择继续实施，不视为业务批准。显式 R2/custom from/to 永远优先，不静默改写。接口公开 weekStartsOn=1、presetBoundary=including_today；可集中替换公共工具并重新验证。
