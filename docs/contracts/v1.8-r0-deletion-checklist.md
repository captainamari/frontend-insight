# v1.8 R0 新旧术语与删除清单

本清单以 `requirements-v1.8` 和 `mvp-plan-v1.5` 为唯一依据。R0 是 Pre-1.0 空数据重置，不提供旧数据升级、alias、双写、双读或回填。

## R0 已删除

| 对象                             | R0 处理                                                           | 验证证据                                       |
| -------------------------------- | ----------------------------------------------------------------- | ---------------------------------------------- |
| contract v1/v2 schema 与生成类型 | 删除，只导出 v3                                                   | contract 负向 fixture 与 `pnpm contract:check` |
| 旧公共字段与 event alias         | 从 SDK、ingestion、Kafka、ClickHouse、DTO、fixture 和 UI 绑定删除 | `pnpm canonical:check`                         |
| 旧 metric key                    | 从运行时代码、SQL alias、seed 与正向 fixture 删除                 | manifest forbidden aliases 与扫描器            |
| MySQL 001–004 增量链             | 删除，替换为单一 `001_v18_baseline.sql`                           | migration inventory test 与空库 verifier       |
| ClickHouse 001–005 增量链        | 删除，替换为单一 v3 `001_v18_baseline.sql`                        | migration inventory test 与空库 verifier       |
| v1/v2 正向与 golden fixture      | 删除，替换为 v3 valid/invalid/golden                              | `pnpm test:r0`                                 |
| 旧 SDK identity/storage 名       | 删除，SDK 0.4 只暴露 `setUser` 与 v3 device ID                    | Web tracker 单元与浏览器 contract              |

旧名仅允许出现在历史文档、manifest 的 `forbiddenAliases`、本差异清单和负向 fixture；allowlist 由 `tools/check-canonical-names.mjs` 显式维护。
