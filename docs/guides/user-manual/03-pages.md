# 03 · 页面质量与运营

[返回目录](README.md) · 前一篇：[概览与业务](02-overview-and-business.md) · 下一篇：[指标与分数](04-metrics-and-scores.md)

左侧“页面分析”有“质量分析”和“运营分析”两个 TAB。二者沿用项目、环境和时间上下文，但回答不同问题：前者找错误实例，后者分析页面访问、使用方式和目标。

## 从一条错误定位可复查的问题

**前提：** 业务应用产生并上报了错误；事件已经可查询；所选环境和时间包含该事件。错误实例查询不以质量分数版本已激活为前提。

1. 打开“页面分析” → “质量分析”，先核对顶部环境、时间及项目时区。
2. 在“查找路径”输入路径片段，缩小下拉候选，再在“页面路径”选中实际路径。输入搜索文字本身只是查找候选，不等于已应用页面筛选。
3. “错误类别”可选全部、API / Ajax、Resource、Vue、React、Promise、JS、Other。初次排查不确定分类时用“全部类别”。
4. “实例范围”默认“每组最新一次”，用于快速看问题类型；想调查某组频次和条件，展开“错误组”并点“查看此组全部实例”，或选择“全部实例”。
5. 查看路径、发生时间、堆栈、类别和 Release；点击“复现条件”，核对发布版本、浏览器家族、系统、视口档位、导航类型、请求方法／路径／状态码及最近安全操作。
6. 记录错误组完整 ID、实例时间和当前链接，连同业务操作步骤交给处理人；不要只发一张截掉环境和时间的错误截图。

**预期：** 能复查“哪个版本、哪个环境、什么路径、何时、哪类错误、有哪些已采集上下文”。“安全复现条件”提供的是有限字段，不是完整会话回放；缺失字段显示“未采集”，不应自行补出用户输入或请求体。

## 分页、刷新与实时查看

- “每组最新一次”显示的表格行数不是错误总次数。看上方“组／次”和组详情区分去重后的问题与发生次数。
- 点击“下一页”继续当前分页快照；快照保留一小时。过期或筛选改变后，点“回到第一页”或“第一页”。
- **页面内“刷新”**：如果选择最近 7 天等预设范围，会把起止边界重新解析到当前时间并清除旧游标，保留路径、类别、错误组和模式。
- **自定义范围**：刷新只重新查询原日期，不擅自扩大范围；想看新事件需要自己修改结束时间。
- **浏览器 F5／复制旧链接**：保持 URL 里的时间快照。仅 F5 不保证把刚发生的错误包含进来。
- 若正在查看单一旧错误组，新产生的其他组不会出现在结果里；点击“返回全部错误组”后再查。

状态文字“所选范围暂无错误实例”只说明该范围没有已观测记录。查看“最早可用实例”“查询快照”和采集链路原因，判断是确实没有收到、尚未消费还是条件不匹配。链路恢复后可再次点击“刷新”。

## 从页面访问判断使用状况

入口：“页面分析” → “运营分析” → “页面路径”。

1. 选择要分析的页面；没有明确目标时从全部页面开始。核对数据状态、指标版本与“当前窗口最早事实”。
2. 读“UV 构成”：已识别、匿名设备和缺失身份。登录前后不会推定为同一人，因此 UV 不是天然的真实员工人数。
3. 查看绑定的指标卡片、单位、定义版本及缺失原因。没有预期指标时，请管理员检查运营版本与“页面运营展示指标（版本化）”。
4. 看“同源趋势”，展开“全部绑定指标趋势及缺失原因”；检查某天是下降、空白还是缺失。
5. 看“自然周期活跃用户”和“本地小时分布”，理解何时有人使用。
6. 看“扩展诊断”的时长有效样本、缺失 `page_leave`、coverage、页面深度与模块广度。
7. 在“页面配置及目标”核对页面模板、模块、核心状态、使用频率、权重和 revision 生效区间；有疑问交给管理员。
8. 看“页面工作流 / 任务”，把访问与任务结果联系起来。

**预期：** 可以形成“页面有访问，但时长样本缺失，暂不能评价停留目标”这类有边界的判断；不能把每个空白都当零。

## 常见指标怎么读

| 名称                       | 使用方式与边界                                                                    |
| -------------------------- | --------------------------------------------------------------------------------- |
| PV                         | 页面访问量；适合看流量变化，不代表独立人数                                        |
| UV                         | 当前范围规范身份／匿名设备去重，结合身份构成解释；不要将多个日期 UV 相加当范围 UV |
| VV                         | 当前查询范围内按原有 sessionId 去重的会话数，不能与 PV 互换                       |
| DAU／WAU／MAU 自然周期明细 | 按项目日、周一开始的周、月与所选窗口相交统计；部分周期不外推，跨周期不相加        |
| 页面可见时长               | 依赖有效页面离开／时长事实；未收到 `page_leave` 是缺失，不是停留 0 秒             |
| 跳出率（单页会话率）       | 诊断信息，不默认告警；单页完成任务可能完全合理                                    |
| 页面／模块深度 P50         | 中位观察；纯未归类会话可能被排除，要看有效与排除样本                              |
| 本地小时分布               | 使用项目时区；夏令时重复小时合并去重，未观测小时保留空白                          |

“页面工作流 / 任务”依赖页面绑定的 operation key；同模块存在某工作流并不等于它已经关联该页面。发现页面访问很多却没有任务数据时，请同时检查显式关联和业务事实接入。

## 未归类页面怎么处理

管理员可使用“配置页面、目标与展示绑定”进入指标管理；当前页面无定义时会带入路由，帮助创建定义。只读用户联系管理员提供当前路径及应属模块。

配置完成后核对生效时间。页面模板、模块、关键度等变化会创建新 revision，历史查询继续按当时版本解释；刚配置完不能期待所有旧观察自动变成当时已配置的页面。

## 大范围查询与错误恢复

遇到“查询预算”提示时，优先缩短时间；页面筛选可以帮助定位，但质量查询的路径筛选不保证减少底层扫描量，不能承诺选单一路径就解除预算限制。不要无限重复“重试”。页面运营与质量分析均有查询保护预算，按各自提示缩小范围；实现限制由维护者参考 [开发排障学习文档](../../learning/17-v1.8-maintenance-labs-and-troubleshooting.md) 核对。错误页面不是业务零值，保留提示并交维护者。
