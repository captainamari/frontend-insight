# R5 统一手工验收（Mac）

适用：R5-A collector/事实 + R5-B质量TAB。先核对PR交接的最终SHA和Actions成功状态；自动化不等于Jesse手工验收。

## 保留数据启动

```bash
git fetch origin
git switch agent/v1-8-r5b-page-quality-ui
git pull --ff-only
./scripts/dev up-preserve
./scripts/dev smoke
```

不运行reset。Docker和本地依赖排查沿用R5-A Mac指南。

## 验收步骤

1. 按[R5-A业务接入](v1.8-r5a-business-integration.md)在受控页面显式启用质量扩展；参考[R5-A验收](v1.8-r5a-local-acceptance-macos.md)验证真实分母、首屏/列表/longtask、白屏和版本不变。
2. 新建受控错误：`quality.captureException(new Error('local test'), 'vue')`；React传`react`；Promise可通过未处理拒绝或显式安全分类验证。分类不依赖上传源码/DOM。
3. 打开项目→页面分析，默认“质量分析”。上方选对应环境、最近7天或自定义起止时间。注意时间使用项目时区，结束不含。
4. 输入部分路径并单选页面，选择Vue/React/Promise/API/资源等类别；确认只有所选路径/类别的实例。API 500/网络/超时应出现，HTTP200业务拒绝和主动取消不应出现为技术错误。
5. 检查路径、秒级时间、安全首帧、类别、Release；错误组折叠展开，查看此组全部实例，再返回全部组。默认是每组最新一次。
6. 切换全部实例并翻页，确认无重复/遗漏；刷新或复制URL到已授权浏览器，路径、日期、类别和模式恢复。旧游标过期或篡改应提示回到第一页。
7. 用Tab定位“复现条件”，Enter打开，查看浏览器/OS/视口/SDK/schema/安全API及最近操作；Escape关闭并恢复焦点。缺失字段应显示未采集；不得出现query、header、正文、DOM或原账号。
8. 切换无错误的环境/时间，显示暂无实例及覆盖说明，不显示满分或“没有错误”。范围变化不能残留旧抽屉内容。
9. viewer可读已授权项目的同一页面；撤销成员后应拒绝访问，无权访问其他项目。质量页面不提供配置写入。
10. 回归项目概览、业务分析、指标版本管理及既有R4-C入口。R6运营TAB保持待开放。

记录：最终commit、机器/浏览器、各步骤通过/失败、截图、requestId。完成后由Jesse确认统一验收结果，不由代理预填。
