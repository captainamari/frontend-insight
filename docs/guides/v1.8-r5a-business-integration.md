# R5-A 业务接入

先在平台登记页面与所属模块；未归类或历史revision不匹配的页面只保留观察，不生成正式值。

基础SDK兼容0.8协议，质量载荷版本独立为r5a-1。质量扩展需显式导入，所有collector默认关闭。不要同时开启旧observability和新质量JS/Vitals采集，避免重复观察。

```ts
import { createTracker } from "@frontend-insight/web-tracker";
import { createQualityCollectors } from "@frontend-insight/web-tracker/quality";

const quality = createQualityCollectors({
  vitals: true,
  firstScreen: true,
  lists: true,
  longtasks: true,
  api: true,
  resources: true,
  jsErrors: true,
  breadcrumbs: true,
  sampleRate: 1,
  blankScreen: { routes: { "/orders": "#app-root" } },
});
const tracker = createTracker({
  appId: "your_app_id",
  env: "prod",
  release: "your-release",
  endpoint: "/v1/events",
  initialUserId: "u_opaque_business_reference",
  quality: quality.factory,
});

// 已有宿主渲染流程确认完成时调用，不能用window.load代替业务首屏。
quality.firstScreen();
const finishList = quality.startList(rows.length);
await renderRows(rows);
finishList();

// route使用固定接口模板，禁止token/query/header/body/raw ID。
const response = await quality.observeApi("/orders/:id", () => fetch(url), "GET");
// HTTP200业务拒绝不调用技术错误API，继续沿用业务operation结果采集。
// 仅包裹你真正管理的资源加载Promise；不要假装自动覆盖所有浏览器资源。
await quality.observeResource(() => loadControlledResource());
quality.action(); // 只记录固定“action”枚举，无文本/表单参数。
quality.captureException(error);
// SPA路由由基础SDK结算；宿主组件卸载时调用：
tracker.destroy();
```

API适配器返回原对象、抛出原异常。超时需宿主真实超时异常 `TimeoutError`，主动取消为 `AbortError`。资源Promise必须以真实加载失败reject，不能把内部吞掉的失败当成功；未使用适配器的资源不在分母内。

白屏3秒规则只适用于已登记模板的根容器，根内应有业务子元素。根缺失或无子元素算命中；无检测结果不是正常。Vitals只属于文档首次页面，不把初始LCP移动到下一SPA路由；无交互的INP保持无样本。

查询使用env、ISO from/to及可选规范pageRoute。返回分子/分母、observedValue、正式value、sampleSize、coverage、分位数、definitionVersion、thresholdVersion、原因。当前窗口处于24h迟到期时正式值null，观察值仍可诊断；闭合/采样/丢失/零分母/不足样本都不会伪造0或满分。89天以外拒绝完整性，单次扫描上限100万行、返回上限5万事实、API最多100series/Top20。

升级质量定义：在已有指标版本API创建quality草稿，再 `POST /api/projects/:id/metrics/versions/:versionId/quality-facts`，body `{}`；沿用现有评审/激活。旧active不变。查询传 `versionId` 检查binding；历史定义返回 `QUALITY_DEFINITION_UPGRADE_REQUIRED`，不得用新事实重解释旧版本。不要为验收重置已有环境。
