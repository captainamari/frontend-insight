# R5-A 业务接入

先在平台登记页面与所属模块；未归类或历史revision不匹配的页面只保留观察，不生成正式值。

基础SDK兼容0.8协议，质量载荷版本独立为r5a-1。质量扩展需显式导入，所有collector默认关闭。不要同时开启旧observability和新质量JS/Vitals采集，避免重复观察。

```ts
import { createTracker } from "@frontend-insight/web-tracker";
import { createQualityCollectors } from "@frontend-insight/web-tracker/quality";

const quality = createQualityCollectors({
  vitals: true,
  firstScreen: true,
  lists: true,
  longtasks: true,
  api: true,
  resources: true,
  jsErrors: true,
  breadcrumbs: true,
  sampleRate: 1,
  blankScreen: { routes: { "/orders": "#app-root" } },
});
const tracker = createTracker({
  appId: "your_app_id",
  env: "prod",
  release: "your-release",
  endpoint: "/v1/events",
  initialUserId: "u_opaque_business_reference",
  quality: quality.factory,
});

// 已有宿主渲染流程确认完成时调用，不能用window.load代替业务首屏。
quality.firstScreen();
const finishList = quality.startList(rows.length);
await renderRows(rows);
finishList();

// route使用固定接口模板，禁止token/query/header/body/raw ID。
const response = await quality.observeApi("/orders/:id", () => fetch(url), "GET");
// HTTP200业务拒绝不调用技术错误API，继续沿用业务operation结果采集。
// 仅包裹你真正管理的资源加载Promise；不要假装自动覆盖所有浏览器资源。
await quality.observeResource(() => loadControlledResource());
quality.action(); // 只记录固定“action”枚举，无文本/表单参数。
quality.captureException(error);
// SPA路由由基础SDK结算；宿主组件卸载时调用：
tracker.destroy();
```

API适配器返回原对象、抛出原异常。超时需宿主真实超时异常 `TimeoutError`，主动取消为 `AbortError`。资源Promise必须以真实加载失败reject，不能把内部吞掉的失败当成功；未使用适配器的资源不在分母内。

白屏3秒规则只适用于已登记模板的根容器，根内应有业务子元素。根缺失或无子元素算命中；无检测结果不是正常。Vitals只属于文档首次页面，不把初始LCP移动到下一SPA路由；无交互的INP保持无样本。

查询使用env、ISO from/to及可选规范pageRoute。返回分子/分母、observedValue、正式value、sampleSize、coverage、分位数、definitionVersion、thresholdVersion、原因。当前窗口处于24h迟到期时正式值null，观察值仍可诊断；闭合/采样/丢失/零分母/不足样本都不会伪造0或满分。89天以外拒绝完整性，单次扫描上限100万行、返回上限5万事实、API最多100series/Top20。

升级质量定义：在已有指标版本API创建quality草稿，再 `POST /api/projects/:id/metrics/versions/:versionId/quality-facts`，body `{}`；沿用现有评审/激活。旧active不变。查询传 `versionId` 检查binding；历史定义返回 `QUALITY_DEFINITION_UPGRADE_REQUIRED`，不得用新事实重解释旧版本。不要为验收重置已有环境。

## 计算口径与版本核对

| 指标                            | 样本或公式                                                  | 主值                     |
| ------------------------------- | ----------------------------------------------------------- | ------------------------ |
| lcp / inp / cls                 | 同一PV同指标取最新有效序号，按窗口重算                      | P75                      |
| fcp / ttfb / first_screen_time  | 有效页面性能样本                                            | P90                      |
| api_duration                    | 受控请求全部终态的耗时，含失败与取消                        | P50                      |
| api_slow_top                    | 固定接口模板分组；慢请求为耗时>1000ms；保留成功率、慢请求率 | 按P90排序的Top20，非标量 |
| list_render_duration            | 唯一样本ID去重；三个行数桶分别统计                          | P90                      |
| longtask_count / longtask_total | 每PV结算后窗口求和，耗时单位ms                              | 总数 / 总时长，非比率    |
| js_error_rate                   | JS异常次数 / PV数，可大于1                                  | 比率                     |
| api_error_rate                  | HTTP>=400、网络、超时错误请求 / 全部受控尝试                | 比率                     |
| resource_error_rate             | 受控资源失败数 / 受控资源尝试数                             | 比率，仅覆盖显式接入范围 |
| blank_screen_rate               | 白屏命中PV / 启用该规则PV                                   | 比率，必须全部已判定     |
| breadcrumb                      | 最多50条安全上下文，随错误发送                              | 结构化数据，非标量       |

P50/P75/P90/P99采用排序样本线性插值：位置为 `(n-1)*p`，在相邻值之间插值；跨桶/窗口必须重算，不能平均已有分位数。所有数值保留sampleSize及coverage的observedViews/enabledViews/settledViews；minimumSample来自所选定义快照。无交互INP不补0。

质量事实定义版本为 `r5a-facts-2026-10-04.1`；载荷 `r5a-1`；阈值分别是 `web-vitals-5.3.0`、`api-slow-1000ms-v1`、`root-empty-3s-v1`。HTTP200业务拒绝在技术成功分子内，AbortError在总分母内但不计成功或技术错误。

常见不可用原因：`ZERO_DENOMINATOR`（真实分母为0）、`COLLECTOR_DISABLED_OR_UNSUPPORTED`、`PARTIAL_COLLECTOR_COVERAGE`、`INCOMPLETE_OR_SAMPLED_PAGE`、`API_TERMINALS_MISSING`、`RESOURCE_TERMINALS_MISSING`、`BLANK_RULE_NOT_SETTLED`、`INSUFFICIENT_SAMPLE`、`FACT_CONFLICT`、`PAGE_SCOPE_NOT_VERIFIED`、`IDENTITY_NOT_VERIFIED`、`LATENESS_WINDOW_OPEN`。所选版本还可能返回 `QUALITY_DEFINITION_UPGRADE_REQUIRED`、`VERSION_METRIC_DISABLED_OR_MISSING`、`VERSION_RANGE_BOUNDARY`；这不是请求失败，不能在业务层改成0。

单项目既有 `score-management/versions/:versionId/result` 和历史试算使用相同质量事实与评分求值器；默认权重不变。项目列表批量评分保持原查询预算及保守不可用状态，本阶段不扩展完整质量产品。模块范围未证明时返回 `QUALITY_MODULE_SCOPE_NOT_VERIFIED`，不把项目聚合假作模块事实。
