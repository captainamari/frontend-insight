## 联合手工流程

1. 登录→全部项目，设置搜索/排序/分页→进入项目概览。核对path项目、五个导航、账号退出、无全局项目下拉。检查双分数解释中的版本、样本和不可用原因。
2. 修改公共时间/env。确认项目 IANA 时区、周一起点、包含今天的预设、显式from/to优先；刷新、分享、前进/后退恢复。跨DST/月末与长范围保留原范围，不静默截断。
3. 从概览进入业务分析，单选模块，切换其他模块再返回。核对 URL moduleId、标题、卡片、趋势、页面构成与版本一致；同一用户跨页面不可累加UV。
4. 点击指标解释，检查定义、配置revision、样本、身份/排除、时间覆盖和来源；进入对应指标定义/版本，再“返回原业务分析”。返回全部项目应恢复步骤1列表上下文。
5. admin 查看/编辑业务展示bindings到草稿→review→激活，确认原overview bindings范围未变；viewer仅查看，伪造PUT应403。跨项目moduleId或无权限直接API不应泄漏细节。
6. 检查缺口不连线、真实0保留、版本切换分段、同单位至多4条非堆叠线，混合单位分组；打开文本等价表。键盘导航模块/卡片/抽屉，Escape关闭，焦点可见，Home/End滚动卡片。
7. 快速切换env/时间/模块，并在解释打开期间切换上下文。旧请求不得污染新上下文。相同上下文断网刷新应显示带数据身份的stale与失败重试；撤权后清除受保护数据。
8. 页面/模块停用或归属修改只按事件时刻revision生效，不重写历史。查看当前工作流定义和“工作流事实将在 R4-B 接入”，不得出现演示漏斗或耗时。
9. 记录实际浏览器、提交、执行时间、结果和缺陷；截图仅在真实执行时产生。渗透率局部语义未确认与最终CI门禁未全部成功前，不签署完整R4-A验收通过。
