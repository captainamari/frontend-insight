# R7 设置接入、外部接口与手工验收

本指南不是已执行手工验收的记录。R6 仍待朋友验收，R7 不自动合并或部署生产。

Ubuntu 22.04 环境安装、密钥权限、首次管理员和 HTTPS 配置请使用 [生产部署指南](production-ubuntu-22.04.md)，不要照搬本地开发栈的 reset 或测试账号。

## 环境与迁移

按现有 Docker 本地部署流程构建、迁移和启动。新增 MySQL 007；复用原 probe/export 表，不重置数据库。真实测试使用独立 TEST ONLY 项目。访问项目正式设置入口；新项目仍在“全部项目”创建。

## 接入

1. 管理员配置项目时区、Origin 和成员；viewer 只读，不能写配置或签发凭证。
2. 复制页面的实际 appId、endpoint、固定版本 ESM 代码和 CSP。业务应用自行引入；不会远程升级。跨域使用时将脚本来源加入 script-src、接收来源加入 connect-src，并把业务 Origin 加入项目白名单。
3. SDK 初始化必须包含 appId、env、release、endpoint；归一化页面路由不含 query。可选 `setUser` 只接收后端生成的不透明引用；不传账号凭证或原始身份。
4. “发送测试事件”使用当前环境，仅管理员操作。依次观察 sending、accepted、awaiting_storage、queryable。请求 202 仅表示进入队列；以事件 ID/请求 ID 实际查询证实入库和可查询。轮询超时保留待证实，不显示成功入库。
5. Origin 拒绝检查完整 scheme/host/port；blocked 检查探针策略；队列或存储故障检查 Kafka、consumer、ClickHouse；保留 request ID。顶部数据状态为项目级诊断，不替代测试事件独立证据。

## 探针

在所选项目/env/时间范围查看真实事件分母、去重版本占比、契约和最后事件时间。空范围无数据。创建/编辑/删除策略均审计；blocked 必须明确勾选拒绝新事件。删除策略恢复未配置行为；不会删除或重解释历史事件。

## 外部接口

四个固定类型：metric_snapshot、metric_trend、quality_summary、prometheus。创建时选择环境、允许查询起止时间、单次最长天数、凭证过期时间、每分钟请求上限；初始关闭。

启用/轮换返回仅一次明文，刷新和切换上下文即清除；后续列表无法读回。请求示例：

```bash
curl --fail-with-body \
  -H "Authorization: Bearer $FI_EXPORT_TOKEN" \
  'https://YOUR_HOST/api/external/projects/PROJECT_UUID/metric_snapshot?env=prod&from=2026-10-01T00:00:00Z&to=2026-10-07T00:00:00Z'
```

凭证独立于 appId。from/to 为带时区 ISO，左闭右开，不允许未来终点或越权环境。quality_summary 默认每页 20 组，使用返回 nextCursor；其它接口不接受 cursor。禁止 SQL、formula、fields、groupBy。拒绝响应仅安全 code/requestId。停用/撤销立即拒绝新请求；轮换没有旧凭证宽限期。所有凭证共享接口分钟计数，数据库授权不缓存。

Prometheus scrape 使用相同授权和绝对范围查询参数。标签只有 service/env/state/type；分数缺失时不伪造零，availability 为 0。JSON 接口提供完整版本/数据状态/趋势分段血缘。

## 异常规则与审批

界面配置是未批准草稿示例。逐项评审规则、阈值、样本、环境、角色、工作时间与例外，然后由 owner 登记实际管理层/安全批准者、日期、来源及声明。只能启用已批准版本；修改复制为新草稿并重新评审。

观察非工作时间、历史操作量、多设备证据；缺失多 IP 或权限拦截事实必须显示不可计算。历史基线仅已有操作日，不能推定完整流量。共享账号、出差和值班需在已批准版本显式排除。角色范围外看不到命中证据。查看/命中/导出和配置变更都有审计；不做个人绩效排行。

## 验收清单

- admin/viewer、无项目权限、跨项目凭证均由服务端拒绝。
- SDK 代码实际运行；测试事件入库可查；blocked 真实拒绝。
- 默认关闭、一次明文、hash 存储、轮换、过期、撤销、停用、限流、request ID 与审计。
- 固定字段与时间边界；Prometheus 不含路由/身份/错误消息标签。
- 刷新、分享链接、环境范围切换、快速项目切换、空态、加载和错误恢复。
- 真实异常规则审批和缺失事实仍须单独完成，不因测试 fixture 通过而标记通过。

## 可手算的测试口径

以下均为测试 fixture，不是业务默认阈值或真实批准。

| 场景         | 输入                                               | 预期                                                     |
| ------------ | -------------------------------------------------- | -------------------------------------------------------- |
| 版本分母     | a=0.8.0，重复 a，b=未知，c 在 to 边界              | 去重后分母 2；0.8.0 与 unknown 各 50%；c 排除            |
| 非工作时间   | UTC 同用户两个不同操作，阈值=2，最小样本=2         | 2 ≥ 2 命中；重复操作不增加计数                           |
| 工作时间边界 | 上海时区 09:00 和 18:00，工作时间 [09,18)          | 09:00 在工作时间内；18:00 在外                           |
| 历史基线     | 两个历史有操作日各 1 次；当前 24h 2 次；倍数=2     | 基线=1，观察量=2，恰好达到倍数；只剩一个历史日则样本不足 |
| 多设备       | 两个去重操作分别来自两个设备                       | 设备数=2；不据此推导 IP 数                               |
| 共享/例外    | 同用户在 sharedSubjects，或出差/值班区间与查询重叠 | 整个用户窗口排除，observed=null                          |
| 缺失事实     | 只有 page_view 或设备标识                          | 多 IP/权限拒绝返回 not_collected，不填 0                 |

## 手工检查页面上下文

1. 复制含 `env/range/from/to/tab` 的设置链接，换浏览器或刷新；确认项目、环境、范围和 TAB 一致。
2. 快速切换两个项目及环境，确认最终 appId、策略、接口、规则全部属于最终项目；旧请求不得覆盖页面。
3. 在接口 TAB 启用测试接口，立即切换项目或刷新；明文凭证消失，列表与审计不能恢复明文。编辑 scope 会停用接口并撤销旧凭证，必须再次启用。
4. 选择没有事件的范围，版本占比显示空态；模拟 API 不可用后观察错误及重试，不能将错误画成零事件。
5. 使用 viewer 和未加入项目的普通账户分别验证页面与直接 HTTP 写请求；不能只检查按钮隐藏。
6. 调查与导出只能查看批准版本允许的角色范围。批准人、来源和日期必须是真实评审记录；不得照抄测试审批 fixture。

最近调用时间/状态反映服务端请求处理结果；授权后查询失败也写入结果审计。没有授权/撤销缓存，因此停用、轮换和撤销后的下一次新请求重新读库。已获准且正在处理中的请求不宣称可被追回。
