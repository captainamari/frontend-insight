## 管理员准备

1. 创建隔离示例项目，Origin设为 `http://localhost:4174`（若用127.0.0.1也登记），启用模块和 `/` 页面。
2. 登记action类型 `edit`（表单受控formId）；登记action类型 `save` 并启用operation lifecycle。
3. 指标管理→分析对象→组织目录，粘贴组件中的隔离JSON示例，调整未来有效期，先保存草稿再发布。只允许受控键及 `u_`不透明用户引用，最多500行。业务方先在自身可信边界替换直接身份；此引用须与SDK setUser一致。不能上传姓名、邮箱、原始工号、部门/角色名称、多角色数组或额外字段。

5. 已发布版本无编辑/删除；同版本重复发布409。viewer不能导入、发布或读取目录个人信息。

## SDK与真实观察

Demo4174输入效率示例appId，安装效率SDK，执行表单与业务结果；代码位于 `apps/demo-app/src/EfficiencyDemo.vue`。它产生3次修改、1次重置、2次提交尝试、1次校验失败；三个独立操作分别success、HTTP200但业务rejected、执行异常unknown。未知不是成功，也不是已确认拒绝。

```ts
const tracker = createTracker({
  appId,
  env: "dev",
  release,
  endpoint,
  registeredFeatures: ["save"],
  forms: {
    enabled: true,
    sampleRate: 1,
    definitions: [{ formId: "edit", fieldKeys: ["status"] }],
  },
  businessOperations: { enabled: true, operationKeys: ["save"] },
});
tracker.setUser(opaqueUserReference);
const form = tracker.trackForm("edit");
// 宿主绑定自己的事件，仅传入固定字段key；不把DOM事件或字段值传入SDK。
form.change("status");
const attempt = form.submit();
if (!hostValidationPassed) attempt.validationFailed();
const result = await tracker.observeBusiness(
  "save",
  executeHostRequest,
  (result) => classifyInTrustedAdapter(result), // 只返回success/rejected/technical_failure/canceled/unknown
);
form.destroy();
```

同一formId重复安装复用handle；重试调用新submit；一次提交的validationFailed重复调用不重复计数。不同formId并发隔离。destroy/SPA导航/身份变化结算一次。采集开关默认关闭；事件使用现有有界队列和8KiB上限；字段最多50个、并发表单10个、每生命周期动作计数10000，超限显式标记。字段key仅参与白名单判断，事件只上传总次数，SDK从不读取值、标签、文案或DOM。

宿主请求返回值/原异常保留；分类器抛错只产生unknown。SDK不解析响应正文，不安装全局fetch包装。源代码示例不包含业务对象引用；重复操作引用仍等待单独隐私评审。

登录→全部项目→概览→业务分析，选择模块/env/范围。操作效率区查看真实观察计数与明确不可用原因；任务耗时/路径沿用R4-B。组织区无目录显示not_collected；有目录仍因未批准隐私策略不发布数值。目录配置入口保留analysisReturn，返回原上下文。

## 三类状态与检查

- **无目录**：未发布可信名册的项目不能出现编制人数或组织比例。
- **partial**：真实表单/业务结果观察不能当作已批准正式比率；缺开始/冲突/未知/未识别不补0。表单窗口与结果完备性决策未解除前不可激活正式结果。
- **保护**：所有组织值、比率、排名保持null；当前是隐私政策待决保护，并非已实现最终小群体算法，不能冒称k阈值验收通过。
